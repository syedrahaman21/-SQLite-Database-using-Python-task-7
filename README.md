 Summary and Findings
This project successfully demonstrates how Python can be used to connect to a SQLite database, perform basic SQL queries, and visualize simple sales data.

 Key Findings:
Total Quantity Sold and Total Revenue were calculated for each product using SQL aggregation (SUM and GROUP BY).

The data revealed the following insights:

Products like Apple and Orange had the highest quantity sold.

Apple generated the highest total revenue due to a higher unit price.

A bar chart was created to clearly visualize the revenue per product, making it easier to compare product performance.

 Insights:
SQL + Python is a powerful combo for quick and effective data analysis.

Even a small dataset can yield useful business insights when visualized.

This setup is ideal for building lightweight analytics tools without requiring a large-scale database or BI solution.
